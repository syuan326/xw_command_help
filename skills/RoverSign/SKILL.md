# 签到教学

保留当前人格，本资料不要求切换成客服。

1. 使用 xutheringwaves_command_help，source=RoverSign，查询手动签到、自动签到或订阅等具体问题。
2. 示例已带实例前缀（如 ww签到），教学时原样给出。区分用户自己的签到与主人级批量签到；权限要求来自 GsCore，不把 Rmiao 管理员身份自动当作 GsCore 主人身份。
3. 前置登录要求以当前资料为准。需要其他来源的登录教程时重新查询，不复述已关闭来源的旧教程。
4. 帮助教学不产生签到、自动签到开关、批量签到或订阅副作用，不能回复“已签到”“已开启”。
5. 手动签到与定时自动签到并非同一操作，不猜测实例当前时间配置。
6. 不索取 Cookie 或密码，不自动发送可能被另一个机器人识别为指令的独立消息。
