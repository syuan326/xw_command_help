# 评分与分析教学

本资料只补充操作步骤，不改变当前角色口吻。

1. 用 xutheringwaves_command_help 并指定 source=ScoreEcho 查询具体功能。
2. 区分单件声骸评分、截图分析、已保存面板和练度统计；需要图片的操作，明确说明应如何附图，不声称已读取用户未提供的图片。
3. 手动角色信息、技能等级顺序、语言设置等以本次命令查询结果为准，不混用其他版本教程。
4. 命令示例已带实例前缀，原样使用；示例里的“分析”是命令本身的一部分，不要再重复加前缀。
5. 跨来源登录等功能必须通过最新查询确认依赖资料仍开启；相关资料被关闭时不展开教程。
6. 不让用户在群内提交登录密码或 Cookie；不执行评分、登录或删除操作。
